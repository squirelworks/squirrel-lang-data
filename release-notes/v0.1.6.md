# squirrel-lang-data v0.1.6

Draft. Everything merged since v0.1.5, collected as it lands.

Nine partial meaning-matrix columns reach every row, including Klingon's
code-pack instructions, so squirrelator's Pipeline and the Translation
Learner can work end to end in Arabic, Hindi, Hebrew, Thai, Bengali,
Armenian, Georgian, Tamil and Klingon. Twenty-one kana and kanji stroke
paths that failed LanguageStudentDesk's final-frame check are redrawn.

## Meaning matrix

- **Arabic, Hindi, Hebrew and Thai filled to every row** (#111). Arabic
  and Hindi from 34 to 103 rows each; Hebrew and Thai from 55 to 103.
  Written for this project. Mechanical `REVIEW.md` entries for those four
  languages (validators and structure only; native-speaker review still
  needed). Wiktionary and Wikipedia lemma checks cited in `SOURCES.md`.
- **Bengali, Armenian, Georgian and Tamil filled to every row** (#112).
  Bengali from 50 to 103, Armenian from 53, Georgian from 54, Tamil from
  52. Written for this project; lemma checks cited with the same
  Wiktionary and Wikipedia rows in `SOURCES.md`.
- **Klingon filled to every row, including the code pack** (#113). From
  17 to 103 rows. The prior 17 renderings are kept. Code rows use the
  singular object imperative (`mu' yIcha'.`, `qIb yItagh.`). Bare
  `Dajatlh'a'` still cannot be a second rendering of "Do you speak
  Klingon?" under `columns@1`, so that sentence stays
  `tlhIngan Hol Dajatlh'a'`. A separate Wiktionary (Klingon entries) row
  is in `SOURCES.md`.

With these fills, every tested meaning-matrix column that already existed
now has all 103 rows (the 89 sentences and the 14 code-pack
instructions). Columns for the languages that still have none are not in
this release.

## Strokes

- **Kana and kanji redrawn for the stroke final-frame check** (#114).
  Hiragana う ぐ ぶ ぷ, katakana ク グ ト ハ, and kanji 九 了 仁 今 八
  古 合 含 心 必 斗 比 礼. Stroke counts and order still follow KanjiVG;
  shapes are pulled toward Noto Sans JP centre lines so
  LanguageStudentDesk strokecheck coverage and precision pass. Hangul ㅇ
  and Tifinagh ⴰ stay on the baseline for a later seam. After this tag
  is pinned, a LanguageStudentDesk PR should drop these 21 entries from
  `baseline.json`.

## Not in this release

- A human review of the Syriac (Estrangela) strokes against a writing
  primer, and `languages/aramaic/REVIEW.md`.
- Hangul ㅇ and Tifinagh ⴰ stroke fixes.
- Native-speaker reviews of the new and filled columns (the Arabic,
  Hindi, Hebrew and Thai `REVIEW.md` entries are mechanical only).
- Columns for the 19 languages that still have none
  (squirelworks/squirrelator#26).
