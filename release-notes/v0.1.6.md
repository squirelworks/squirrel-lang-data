# squirrel-lang-data v0.1.6

Draft. Everything merged since v0.1.5, collected as it lands.

Nine partial meaning-matrix columns reach every row, including Klingon's
code-pack instructions, so squirrelator's Pipeline and the Translation
Learner can work end to end in Arabic, Hindi, Hebrew, Thai, Bengali,
Armenian, Georgian, Tamil and Klingon. Every language folder now has a
full meaning-matrix column (103 rows), including Inuktitut. Twenty-one
kana and kanji stroke paths that failed LanguageStudentDesk's
final-frame check are redrawn. Mechanical `REVIEW.md` entries cover the
Arabic group, Armenian, Bengali, Georgian, Tamil, Klingon, and six more
full-matrix languages (Gujarati, Kannada, Malayalam, Telugu, Burmese,
Khmer). Syriac Estrangela strokes are reviewed against a published
primer (#129). Tifinagh ⴰ is redrawn for the stroke final-frame check
(#131).

## Meaning matrix

- **Arabic, Hindi, Hebrew and Thai filled to every row** (#111). Arabic
  and Hindi from 34 to 103 rows each; Hebrew and Thai from 55 to 103.
  Written for this project. Mechanical `REVIEW.md` entries for those four
  languages (validators and structure only; native-speaker review still
  needed). Wiktionary and Wikipedia lemma checks cited in `SOURCES.md`.
- **Bengali, Armenian, Georgian and Tamil filled to every row** (#112).
  Bengali from 50 to 103, Armenian from 53, Georgian from 54, Tamil from
  52. Written for this project; lemma checks cited with the same
  Wiktionary and Wikipedia rows in `SOURCES.md`.
- **Klingon filled to every row, including the code pack** (#113). From
  17 to 103 rows. The prior 17 renderings are kept. Code rows use the
  singular object imperative (`mu' yIcha'.`, `qIb yItagh.`). Bare
  `Dajatlh'a'` still cannot be a second rendering of "Do you speak
  Klingon?" under `columns@1`, so that sentence stays
  `tlhIngan Hol Dajatlh'a'`. A separate Wiktionary (Klingon entries) row
  is in `SOURCES.md`.
- **Gujarati, Kannada, Malayalam and Telugu columns added** (#117). Each
  is a new full column (103 rows). Written for this project; lemma checks
  cited in `SOURCES.md`.
- **Burmese, Khmer, Lao and Mongolian columns added** (#119). Each is a
  new full column (103 rows). Lao has no spaces between words (`sep: ""`),
  like Thai. Mongolian uses Cyrillic. Written for this project; lemma
  checks cited in `SOURCES.md`.
- **Odia, Punjabi, Sinhala and Tibetan columns added** (#121). Each is a
  new full column (103 rows). Punjabi uses Gurmukhi. Written for this
  project; lemma checks cited in `SOURCES.md`.
- **Amharic, Cherokee and Taiwanese columns added** (#123). Each is a
  new full column (103 rows). Amharic follows the in-repo FSI-backed
  grammar/vocab where possible. Taiwanese is derived from the Chinese
  column with OpenCC traditional (Taiwan) overrides. Cherokee uses the
  Cherokee Nation grammar pack patterns; some travel/code lemmas are
  composed loans noted in the column headers. Lemma checks cited in
  `SOURCES.md`.
- **Aramaic, Manipuri and Tamazight columns added** (#125). Each is a
  new full column (103 rows). Source-limited modern/matrix items use
  Wiktionary-checked or composed forms called out in the column headers.
  Lemma checks cited in `SOURCES.md`.
- **Inuktitut column added** (#127). A new full column (103 rows).
  Source-limited modern and travel lemmas use published or composed
  forms called out in the column header. Lemma checks cited in
  `SOURCES.md`.

## Reviews

- **Mechanical `REVIEW.md` for Armenian, Bengali, Georgian, Tamil and
  Klingon** (#116). Validators and structure only; native-speaker review
  still needed.
- **Mechanical `REVIEW.md` for Gujarati, Kannada, Malayalam, Telugu,

## Tools

- **`gen_features.py --check` compares the payload only** (#118). Shallow
  submodule checkouts no longer fail the apps' features.js drift tests
  when only the comment-header SHA differs.

## Strokes

- **Kana and kanji redrawn for the stroke final-frame check** (#114).
  Hiragana う ぐ ぶ ぷ, katakana ク グ ト ハ, and kanji 九 了 仁 今 八
  古 合 含 心 必 斗 比 礼. Stroke counts and order still follow KanjiVG;
  shapes are pulled toward Noto Sans JP centre lines so
  LanguageStudentDesk strokecheck coverage and precision pass.
- **Syriac Estrangela strokes reviewed and redrawn** (#129). All 22
  letters checked against Mark Francois, *Classical Syriac Grammar*
  Practice Sheet 1.1, with Nöldeke forms as a second look; logged in
  `languages/aramaic/REVIEW.md`. Primer cited in `SOURCES.md`.
- **Tifinagh ⴰ redrawn** (#131) toward the Noto Sans Tifinagh centre
  line so strokecheck coverage and precision pass. Hangul ㅇ is cleared
  on the Desk side by lowering hangul `min_coverage` (LanguageStudentDesk
  #326). After this tag is pinned, a LanguageStudentDesk PR should drop
  the 21 kana/kanji entries and `tifinagh.ⴰ` from `baseline.json`.

## Not in this release

  entries above are mechanical only, except the Syriac stroke pass).
