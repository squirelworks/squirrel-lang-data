# squirrel-lang-data v0.1.4

Draft. Items are added here as their PRs merge.

## Meaning matrix

- **A "code" pack for explaining code** (#56). 25 content meanings
  (print, loop, start, end, repeat, count, set, value, variable, number,
  one, three, ten and others) and a grammar meaning, `@until`, for the end
  of a range ("from one *to* ten", Japanese まで). The pack has 14 short
  instructions such as "Print the word." and "Count from one to ten.", so
  squirrelator can explain code in a learner's own language. The Japanese
  column renders all 14, written for this project in the plain dictionary
  form Japanese uses for steps and instructions (単語を表示する。).
- **The Chinese column renders the code pack.** All 14 rows, written for
  this project as short instructions (显示单词。, 从一数到十。), the form
  software and textbooks use for steps.
- **The Korean column renders the code pack.** All 14 rows, written for
  this project in the plain written form (-ㄴ다/-는다) that manuals and
  textbooks use for steps (단어를 출력한다., 하나부터 열까지 센다.).
- **The Latin column renders the code pack.** All 14 rows, written for
  this project as singular imperatives (Verbum ostende., Ab ūnō ad decem
  numerā.). Latin has no words for computing, so a few are long-standing
  Neo-Latin coinages: orbis (loop), variābilis (variable), programma
  (program), tabula (screen).
- **Six more columns render the code pack**: Greek, Russian, Hebrew,
  Arabic, Hindi and Thai, all 14 rows each, written for this project in the
  form each language's manuals and textbooks use for steps. Greek: singular
  imperative, as in Greek school pseudocode (Εμφάνισε τη λέξη., Μέτρησε από
  το ένα μέχρι το δέκα.). Russian: the infinitive of algorithm steps
  (Вывести слово., Повторить три раза.). Hebrew: the infinitive, which
  software uses so steps don't take a gender (להציג את המילה.). Arabic:
  masculine singular imperative, as in Arabic programming textbooks (اطبع
  الكلمة., عُدّ من واحد إلى عشرة.). Hindi: the polite -ें imperative of
  software and manuals (शब्द प्रिंट करें।, एक से दस तक गिनें।). Thai: the
  bare verb, which Thai uses for instructions (แสดงคำ, นับจากหนึ่งถึงสิบ).
- **Four more columns render the code pack**: Georgian, Armenian, Bengali
  and Tamil, all 14 rows each, written for this project. Georgian: the
  second-person imperative (დაბეჭდე სიტყვა., დათვალე ერთიდან ათამდე.).
  Armenian: the singular imperative (Տպիր բառը։, Հաշվիր մեկից մինչև
  տասը։). Bengali: the polite -উন imperative of software and manuals
  (শব্দটি প্রিন্ট করুন।, এক থেকে দশ পর্যন্ত গুনুন।). Tamil: the -அவும் form
  Tamil software uses for commands (சொல்லை அச்சிடவும்., ஒன்று முதல் பத்து
  வரை எண்ணவும்.). Every tested column except Klingon now renders the pack.
- **Latin inflection tables** (#63). languages/latin/inflections.jsonl
  gives every word in the Latin matrix column that inflects (67 entries,
  the code pack included) its forms: nouns, adjectives and pronouns in all
  cases and both numbers (and each gender for adjectives), verbs in the
  present, imperfect and perfect in every person, plus the imperative and
  infinitive. Thirteen grammar meanings name the features: the six cases,
  @plural, three genders and three persons. Written for this project, so
  an engine can decline and conjugate Latin instead of copying the
  matrix's forms. Nouns carry their gender and personal pronouns their
  person, so adjectives and verbs can agree.
- **meta.json "cases" and "order"** (#63). "cases" gives the case a role
  or a preposition's meaning takes (Latin @object is @accusative, from is
  @ablative); "order" gives the usual word order (English SVO), so an
  engine can tell subject from object where nothing marks them.
  check_meta checks both.

- **English inflection tables** (#63). languages/english/inflections.jsonl
  gives 42 verbs of the meaning matrix their -s, past, participle and -ing
  forms (reads, went, spoken, sitting) and 34 countable nouns their plural
  (books, children, buses), tagged with @third-person, @past, @ongoing and
  @plural, so an engine reading English knows the forms and what they say.
- **Klingon affix tables.** languages/klingon/inflections.jsonl gives every
  content word of the Klingon column its forms, built from the affix
  tables: verbs with each subject prefix (jI-, bI-, ma-, Su-), each prefix
  for a third-person object (vI-, Da-, wI-, bo-, lu-, tagged @object), the
  perfective -pu' (@past) and the commands yI- and pe-; nouns with their
  plural (-pu' for beings that speak, -mey for things) and -Daq for places;
  and the personal pronouns with their person. Klingon meta.json gives its
  word order, OVS. Written for this project.
- **More Latin tables.** Seven more words (videō, comedō, nāvis, dux,
  praefectus, cibus and eī for they), so Latin can say what the Klingon
  rows say, and the perfect of the deponents loquor and exsequor (locūtus
  sum). A new content meaning, they.

## Grammar

- **Chinese grammar: 72 lessons** (#66). The course had 12 written
  lessons and 54 planned titles, which is why it stopped at HSK 2. Every
  planned point is now a full lesson, plus six more, from absolute
  beginner to written Chinese (而, 将, 以…为, 所, 之, 其).
- **Japanese grammar: 73 lessons** (#68). Up from 17, running from
  です and the particles to keigo and written Japanese. 42 smaller points
  stay on the plan list.
- **French grammar: 72 lessons** (#69). Up from 6, running from être,
  avoir and articles to the subjunctive, the passé simple and formal
  French.
- **German grammar: 72 lessons** (#70). Up from 6, running from sein,
  articles and word order to the cases, Konjunktiv I and II and the
  passive.
- **Italian grammar: 72 lessons** (#71). Up from 6, running from essere,
  articles and the present tense to the passato prossimo, the subjunctive,
  the conditional and the passato remoto.
- **Russian grammar: 72 lessons** (#72). Up from 12, running from
  the cases and verb aspect to participles, gerunds and the conditional.
  The 20 points that were only on the plan list are now full lessons.
- **Greek grammar: 72 lessons** (#73). Up from 12, running from
  articles and the present to the aorist, the subjunctive, participles and
  the passive. The 17 points that were only on the plan list are now full lessons.
- **Arabic grammar: 72 lessons** (#74). Up from 12, running from
  nominal sentences and the present to the derived verb forms, participles,
  conditionals and the passive.
- **Hindi grammar: 72 lessons** (#75). Up from 12, running from
  है and the present to the past with ने, compound verbs, conditionals,
  the passive and causatives.
- **Bengali grammar: 72 lessons** (#76). Up from 12, running from
  the present and the classifiers -টা and -টি to the conjunctive participle,
  conditionals, compound verbs and the passive.
- **Hebrew grammar: 72 lessons** (#77). Up from 12, running from

- **Thai grammar: 72 lessons** (#78). Up from 12, running from

  unreal conditions and royal vocabulary.
- **Tamil grammar: 72 lessons** (#79). Up from 12, running from

- **Telugu grammar: 72 lessons** (#80). Up from 6, running from

- **Kannada grammar: 72 lessons** (#81). Up from 6, running from
  sentences without "is" and case endings to participles, -ಅರೆ for

- **Malayalam grammar: 72 lessons** (#82). Up from 6, running from

- **Gujarati grammar: 72 lessons** (#83). Up from 6, running from
  "to be", the three genders and the present to the past with -એ,

- **Punjabi grammar: 72 lessons** (#84). Up from 6, running from

- **Lao grammar: 72 lessons** (#89). Up from 6, running from

- **Amharic grammar: 72 lessons** (#94). Up from 12, running from
